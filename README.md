# PAC 2 — Visualitzacions de dades

Francesc Lucas Carbó

Tres visualitzacions amb dades obertes: núvol de paraules de Darwin, mapa de trànsit aeroportuari espanyol i rosa mensual de Palma de Mallorca.

Les pàgines inclouen fonts, metodologia, limitacions, taules i CSV descarregables. Les dades estan fixades a 30 d’octubre de 2026.

Web estàtic HTML, CSS, JavaScript i SVG. Publicació amb GitHub Pages des de main, carpeta arrel.
